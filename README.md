NoRollback is a project that removes 99% _(source : trust me)_ of rollbacks.

**You can remove this project from a world after loading a world with it. One use is enough.**

## How it works ?
It sets the game rule `elytra_movement_check` and `player_movement_check` to false.
This allowed to ignore the player's speed limit & speed limit when using elytra, removing most rollbacks at the cost of making easier to cheat on a server. (source : [Minecraft Wiki - Gamerule](https://minecraft.wiki/w/Game_rule))
